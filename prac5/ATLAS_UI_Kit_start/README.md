ATLAS UI Kit. Практическая работа № 5

Выполнил: Донченко Дмитрий Антонович, 2024-ФГиИБ-ИС-2б

Это набор стилей для панели Help Desk. В нём есть светлая и тёмная тема, обычный и компактный режим, кнопки, поля ввода и уведомления. Библиотеки не использовались, только HTML, CSS и JavaScript.


Как запустить

Открыть папку проекта в терминале, выполнить команду py -m http.server 5500 и открыть в браузере адрес http://localhost:5500.


Исходная проблема и план

В начале была готова разметка страницы, светлая тема, общий вид страницы и основная синяя кнопка. Не было тёмной темы, список "Тема" ничего не переключал, две другие кнопки, поля и уведомления не были оформлены, не было компактного режима и предупреждения.

План работы: сделать тёмную тему, затем переключение темы, затем оформить кнопки, поля и уведомления, проверить страницу, а в конце сделать компактный режим и предупреждение.


Как устроены токены

Токены - это переменные, в которых хранятся цвета и размеры. Они разделены на три уровня.

Первый уровень - базовые цвета палитры, например --base-blue-700. Это просто цвет, без назначения.

Второй уровень - роли цвета, например --color-primary. Роль говорит, для чего цвет нужен: основное действие, фон, текст, ошибка.

Третий уровень - настройки конкретных элементов, например --button-bg-primary. Это фон основной кнопки.

Сами стили элементов берут значения только из токенов. Прямых кодов цветов в стилях элементов нет.

Примеры цепочек.

Фон основной кнопки: --base-blue-700 (#1853a4) -> --color-primary -> --button-bg-primary -> .button--primary.

Текст основной кнопки: --base-white (#fff) -> --color-on-primary -> --button-text-primary -> .button--primary.

Фон карточек: --base-white (#fff) -> --color-surface -> .section--card.

Отступ внутри кнопки: --space-5 -> --button-padding-inline -> .button.

Тёмная тема меняет только второй уровень, то есть роли цветов. Компактный режим меняет только третий уровень, то есть размеры элементов. Стили самих кнопок и полей при этом не меняются.


Темы и плотность

Тема включается атрибутом data-theme у страницы. Если выбрана "Системная", атрибута нет и тема берётся из настроек. Если выбрана "Светлая" или "Тёмная", этот выбор важнее настроек системы. Выбор сохраняется в браузере под именем atlas-theme.

Компактный режим включается атрибутом data-density. В нём уменьшены шесть размеров: высота кнопок и полей, отступы внутри них, промежутки между элементами и отступ в уведомлениях. Выбор сохраняется под именем atlas-density.

Тема и плотность сохраняются отдельно и не мешают друг другу. Если браузер не даёт сохранять настройки, переключение всё равно работает.

Ответы на вопросы

Почему плотность задаётся токенами элементов? Все кнопки, поля и промежутки берут размеры из этих токенов. Поэтому для компактного режима хватает поменять шесть значений в одном месте, а не переписывать стили каждой кнопки и поля. Новый элемент на тех же токенах сам получит компактный режим.

Почему в тёмной теме нельзя писать цвета прямо в кнопке? Кнопка берёт цвет из токена, а тёмная тема меняет значение токена в одном месте, и кнопка перекрашивается сама. Если писать цвета прямо в кнопке, пришлось бы делать отдельную тёмную копию стилей для каждого элемента, и что-нибудь обязательно забылось бы.


Два решения, которые я принял

В тёмной теме цвет кнопки при наведении и нажатии темнее обычного, а не светлее. Так белый текст на кнопке хорошо читается в любом состоянии.

Режимы "Системная" и "Обычная" - это отсутствие атрибута у страницы. Обычные значения уже записаны по умолчанию, поэтому отдельные стили для этих режимов не нужны.
